# Student Performance Analysis Using NumPy

## Overview
This project is built using NumPy and Matplotlib to analyze student performance data.

The project generates random marks for students and performs various data analysis operations such as:
- total marks calculation
- average marks analysis
- topper identification
- failed student detection
- grade analysis
- subject-wise performance analysis
- data visualization

---

## Features
- Generate random student marks dataset
- Calculate total and average marks
- Find topper student
- Detect failed students
- Generate grades
- Subject-wise performance analysis
- Bar chart visualization
- Histogram visualization

---

## Technologies Used
- Python
- NumPy
- Matplotlib

## How To Run

1. Install required libraries

```bash
pip install -r requirements.txt
```

2. Open Jupyter Notebook

```bash
jupyter notebook
```

3. Run:
```text
numpy_project_student.ipynb
```


The project dynamically analyzes student performance data and generates insights such as:
- topper identification
- subject-wise performance
- failed student detection
- marks distribution(grades)
