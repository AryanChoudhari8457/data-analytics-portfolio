# Sales Data Analysis Using Pandas

This project focuses on analyzing sales data using Python libraries such as Pandas, Seaborn, and Matplotlib. The main objective of the project is to extract meaningful business insights from the dataset through data cleaning, visualization, and analysis.

## Project Objectives

- Analyze regional and state-wise sales performance
- Identify customer purchasing behavior
- Analyze customer satisfaction through ratings
- Study yearly sales trends
- Understand preferred payment and shipping methods
- Visualize sales insights using charts and graphs

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights

- North region recorded the highest sales count.
- Central region generated the highest sales revenue.
- Punjab had the highest sales count among all states.
- Tamil Nadu generated the highest sales amount.
- Beauty and Clothing were the most preferred categories.
- Home Office segment contributed the highest sales.
- UPI was the most preferred payment method.
- Same Day was the most used shipping mode.
- Most customers provided ratings of 4 and 5, indicating high satisfaction.
- Around 83% orders were not returned.

## Visualizations Included

- Bar Charts
- Count Plots
- Line Charts
- Pie Charts
